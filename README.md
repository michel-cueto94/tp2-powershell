## Descripción

Este repositorio contiene la solución al **Trabajo Práctico N° 2** de la materia Programación para Seguridad Informática[cite: 1]. En este trabajo se desarrollan dos scripts interactivos en PowerShell que implementan entrada y salida de datos por consola, conversión de tipos e interacción con el usuario[cite: 1].

---

## Contenido del Repositorio

El proyecto incluye los siguientes scripts de PowerShell:

* `ejercicio1.ps1`: Solicita el nombre del usuario por consola y devuelve un saludo personalizado[cite: 1].
* `ejercicio2.ps1`: Solicita el número de horas trabajadas y el coste por hora, realiza el cálculo del importe total y muestra por pantalla la paga correspondiente[cite: 1].

---

## Instrucciones de Ejecución

Para ejecutar los scripts localmente desde una consola de PowerShell:

1. Clona o descarga este repositorio en tu equipo.
2. Abre la consola de PowerShell en la ubicación de los archivos.
3. Ejecuta el ejercicio deseado:

```powershell
# Ejecutar Ejercicio 1
.\ejercicio1.ps1

# Ejecutar Ejercicio 2
